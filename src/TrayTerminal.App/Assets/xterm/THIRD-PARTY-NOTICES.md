# xterm.js assets

These files are vendored from official npm packages and are covered by the
adjacent `LICENSE` (MIT):

- `xterm.js`, `xterm.css`: `@xterm/xterm` 5.5.0
- `addon-serialize.js`: `@xterm/addon-serialize` 0.13.0

The serialize add-on declares `@xterm/xterm ^5.0.0` as its peer dependency.
The core and add-on were updated together so the terminal state checkpoint
format is produced and consumed by one explicitly pinned xterm.js generation.
